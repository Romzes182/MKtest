# Установка MKtest 1.0.1 на Windows 7 x64

1. Проверьте `Win + R → winver`: нужна **Windows 7 Service Pack 1**.
   Для Windows 7 без SP1 сначала установите SP1 и обновления системы.
2. Распакуйте весь архив установщика в одну папку.
3. Запустите **setup.exe**. Он проверит наличие **.NET Framework 4.8** и при
   необходимости предложит загрузить и установить его с сайта Microsoft.
   Для установки Framework нужны Интернет и права администратора; после
   установки может потребоваться перезагрузка.
4. Завершите установку MKtest, затем запустите его через ярлык.

Если устройство не подключено к Интернету, на другом компьютере скачайте
[автономный установщик .NET Framework 4.8 с сайта Microsoft](https://go.microsoft.com/fwlink/?linkid=2088631),
перенесите его на устройство и установите. Затем запустите `MKtest.Setup.msi`.
Если Framework уже установлен, можно сразу использовать MSI.
**.NET Framework 4.8.1 для Windows 7 не подходит.**

При ошибке проверки цифровой подписи установщика Framework убедитесь, что
Windows 7 SP1 обновлена: для поддержки SHA-2 нужны KB4490628 и KB4474419.
Обновления и Framework загружайте только с сайта Microsoft.

Версия 1.0.1 заменяет предыдущую MSI-версию 1.0.0. Перед обновлением закройте
MKtest и сохраните резервную копию `%LOCALAPPDATA%\Programs\MKtest`, если меняли
файлы маршрутов или шаблоны JSON. Пользовательский `config.json` и журналы
сохраняются; файлы шаблонов и маршрутов из MSI могут быть заменены.

Приложение устанавливается для текущего пользователя в
`%LOCALAPPDATA%\Programs\MKtest`. Не переносите один EXE отдельно от DLL и данных.
Новый пакет использует системный .NET Framework 4.8, а не встроенный .NET 9.
Отдельно скачивать `api-ms-win-crt-runtime-l1-1-0.dll` не требуется.

Автоматические проверки выполняются на Windows Server 2022. Они проверяют
сборку, тесты, установку и запуск на .NET Framework, но не заменяют проверку
на самом устройстве с Windows 7, включая SSH, обмен с оборудованием и печать.
